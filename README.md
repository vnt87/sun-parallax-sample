# Sun Parallax Sample

This is just a simple deployment to showcase an interaction for my Figma design.

## Credits

This project uses [vanilla-tilt.js](https://micku7zu.github.io/vanilla-tilt.js/), a smooth and lightweight JavaScript library for creating tilt effects. vanilla-tilt.js is a fork of the original [tilt.js jQuery version](https://github.com/gijsroge/tilt.js) by [Gijs Rogé](https://github.com/gijsroge).

### Features used:
- Parallax layering with 3D transforms
- Smooth transitions
- Glare effect
- Mobile gyroscope support
